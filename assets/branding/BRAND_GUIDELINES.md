# Miyazato Spatial Engine — Brand Assets

## Official identity
This package is based on the selected **Option 1** logo and is the official visual identity for the Miyazato Spatial Engine application.

## Recommended usage

- Windows executable / installer: `icons/miyazato-spatial-engine.ico`
- Application UI header/sidebar: `logos/mse-logo-transparent.png`
- GitHub / documentation: `logos/mse-logo-horizontal-dark.png`
- Splash screen: `splash/mse-splash-1920x1080.png`
- Favicon: `icons/favicon.ico`

## Primary visual language

- Graphite / near-black background
- Electric lime accent
- White/silver primary monogram
- Rounded-square icon container
- High contrast, premium audio/technology aesthetic

## Rules

1. Do not stretch or distort the logo.
2. Preserve safe spacing around the mark.
3. Do not recolor the official icon arbitrarily.
4. For new UI components, use the brand tokens in `brand/brand-tokens.json`.
5. Use the transparent version when embedding the mark inside the application.
6. Maintain legibility at small sizes; use the dedicated PNG/ICO exports rather than downscaling the source at runtime.
